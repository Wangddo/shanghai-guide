# 상하이 교양강의

2박 3일 상하이 첫 여행자를 위한 강의 핸드아웃 패키지. **압축 4회.** 폴란드 교양강의(`../lecture`)의 형식 — 시안 A 읽기 핸드아웃, Beat 구조, 좌측 미니목차 — 을 그대로 이어받았다.

- 오프라인: 폴더를 통째로 내려받아 `index.html`을 브라우저로 열면 된다. 외부 의존성 없음.
- 동반 투어 앱: `../tour-shanghai/` (4회차의 토·일 동선을 현장에서 따라가는 PWA)

## 시리즈 (각 60분)

| 회차 | 제목 | 내용 | 파일 |
|---|---|---|---|
| 1 | 상하이라는 도시 — 좌표와 180년 | 장강 하구 · 1553 성벽 → 1843 개항 → 조계의 100년 → 1949 → 1990 푸동 개발. 와이탄(강요된 개방) ↔ 루자쭈이(선택한 개방) | `01-coordinates-history.html` |
| 2 | 조계와 모던 상하이 — 와이탄·석고문·임시정부 | 와이탄 52동 · 석고문과 룽탕 · **1919–1932 대한민국 임시정부**와 윤봉길 · 롼링위·루쉰·장아이링 · 유대 난민 · 오늘의 옛 프랑스 조계 | `02-concessions-modern.html` |
| 3 | 상하이의 일상 — 음식·결제·교통·매너 | 30일 무비자 · 로밍 vs 현지 유심 · 알리페이 + 해외 카드(200元 규칙) · 메트로 카드 태그 · 페리 · 디디 · 본방채·샤오롱바오·털게 · 말 한마디 | `03-daily-life.html` |
| 4 | 상하이 가이드 투어 — 2박 3일 요일별 동선 | 금요일 밤 도착 · 토요일 오전 와이탄·위위안(10, 그랜드마더 점심) · 토요일 오후 옛 프랑스 조계(9, 톈즈팡 옆 양꼬치 → 우캉루 → Flair) · 일요일 루자쭈이(7, 동방명주 입장 → 점도덕 딤섬) · 대안: 루쉰공원(홍커우) | `04-shanghai-tour.html` |

폴란드 시리즈의 "도시별 집중(deep) + 투어" 쌍 구조 대신, 한 도시·짧은 일정에 맞춰 **1–2회 역사·도시(집중) → 3회 실용 → 4회 투어**로 압축했다.

## 일정 전제

- **2026. 11. 20(금) – 22(일)** — 금 22:10 훙차오 T1 도착 → 일 17:00 훙차오 T1 출발 → 김포 19:50 도착
- 11월 하순: 일몰 16:53, 와이탄 조명 21–22시 소등, 8–15°C·비, 털게 제철, 플라타너스 단풍 절정
- 숙소: IFC 레지던스 (푸동 루자쭈이, 메트로 2호선 루자쭈이역 직결)
- 시내만 (근교 당일치기 없음)

## 폴더 구조

```
lecture-shanghai/
├─ index.html                   메인 (전체 강의 카드)
├─ 01-coordinates-history.html  1회차
├─ 02-concessions-modern.html   2회차
├─ 03-daily-life.html           3회차
├─ 04-shanghai-tour.html        4회차
└─ assets/
   ├─ css/  base.css · handout.css · index.css   (폴란드 시리즈에서 복사, 이름만 일반화)
   └─ images/  01–04   회차별 이미지 + credits.txt + _download.sh
```

- `handout.css`의 `.korea-poland` → `.korea-mirror`로 이름을 바꿨다 (한국과의 거울 비교 박스).
- 4회차 정거장 본문은 투어 앱의 `tour-shanghai/course/{sat,sun}/stops-data.js`에서 생성한다. **정거장 내용은 투어 앱 쪽에서 고치고** `node lecture-shanghai/_sync-04.js`로 4회차에 반영할 것 (`@generated` 마커 사이만 다시 쓴다). 4회차 사진(`images/04/`)은 투어 앱 사진과 같은 파일이다(`sat-`/`sun-` 접두어 = 요일).

## 기술 사양

- 외부 의존성 0 — CDN·폰트 파일·빌드 없음
- 시스템 폰트 (Apple SD Gothic Neo / Pretendard / Noto Sans KR)
- 반응형 — 모바일 폭에서 1단 레이아웃 (360px에서 가로 스크롤 없음 확인)

## 이미지 출처

모든 이미지는 Wikimedia Commons (CC BY-SA / CC BY / CC0 / Public Domain). 회차별 저작자·라이선스·원본 링크는 `assets/images/<회차>/credits.txt`, 다시 받으려면 같은 폴더의 `_download.sh`.
